# 青玉棋会

PICO 原生空间自走棋可试玩原型：1名真人与3名本地AI，16名英雄、最高人口7。你淘汰或夺冠即结束本局。

## 试玩

在B3110头显打开“青玉棋会”，当前试玩版V1.10.0。新增连胜/连败金币奖励，技能主图案保持1.2–1.8秒，远程普攻有箭矢或能量球弹道。交战期间可整理备战席、买牌、卖备战棋子、刷新和买经验；当前交战阵容锁定。终局居中显示“胜利”或“失败”，可“再来一局”或“退出”。保留人机延迟经营、每局随机种子和V1.8英雄数值，产物位于dist/v1.10.0。

1. 点击“开始棋会”，立即进入备战并生成五张卡牌，可直接招募。
2. 手柄或眼手按住棋子本体或脚下槽位拖动，松手落入己方四排棋格。拖到商店中央卡牌区域会提示出售金额，松手卖出。也可点选棋子再点目标格或另一棋子；棋盘/备战席占用格双向交换，满人口同样可换。非法落点返回原位。
3. 卫士放前排，射手、法师和辅助放后排。开战时自动从备战席补齐空余人口，保留已有站位；三个同名同星英雄自动合成。交战和结算阶段只合成备战席副本，涉及上场副本的升星到下一轮备战处理。
4. 交战和结算期间仍可买牌、刷新、买经验、拖动交换或出售备战席棋子。上场棋子不能移动、出售或参与合成；战斗买经验升人口后，本场参战人数保持不变，下轮补位。自动布阵只在备战阶段开放。
5. 战斗自动进行，可切换观战。25秒仍未结束进入2倍加速，再交锋15秒仍僵持才比较存活人数/剩余生命比例。胜利立即+1金；落败按“回合基础 + 敌方存活人口”立即扣血。你生命归零的当次结算就结束本局，停止其他未完成战斗；只给已完成战斗的参战者发当轮基础5金、利息、2经验，包括本轮刚被淘汰者。19金胜利最终27，落败25；未完成战斗不虚构结果或发收入。
6. “棋手托管”按相同经济规则自动经营；“接回经营”恢复手动控制。人机首批操作等待2–4秒，购买、升级和最多两批刷新分步完成。点“准备完毕”会让尚未完成的经营按相同付费规则完成，再锁定阵容。灵活经营、偏搜低费、偏升级三种风格每局随机分配给三个人机。
7. 状态区显示八种羁绊：阵营2/4，卫士/法师1/3/5，射手1/2/3，辅助1/3。基础魔抗20，卫士增加双防，辅助提供全队魔抗。范围法术主目标100%、副目标65%；25秒后的治疗、回血与新增护盾减半。
8. 暂停或离开应用会冻结对局。返回后点击“继续”。你淘汰或夺冠时出现居中终局弹窗，显示“失败”或“胜利”、名次及胜场；“再来一局”重置卡池、生命、金币、战斗、计时并切换随机种子，“退出”关闭棋会。真人淘汰时尚存活AI显示“未完赛”。
9. 连胜与连败奖励相同：连续2–3场+1金、4场+2金、5场及以上+3金。胜负反转重新从1场计数，平局清零。HUD显示当前连胜败及加成，奖励在回合结算到账，不参与自身当轮计息；真人与人机一致。
10. 技能保留16种主图案，前60%时间保持亮度，随后淡出；护盾/治疗跟随目标，2倍加速不缩短显示时长。射手普通攻击发射箭矢，法师/辅助发射能量球，飞行0.30–0.55秒并带拖尾；近战保留挥砍。弹道为视觉表现，原伤害结算时机保持不变。暂停冻结当前效果，换场和重开清理旧效果。

商店概率只跟人口等级变化，与回合无关。1/2/3费：3人口75/25/0%，4人口55/30/15%，5人口45/33/22%，6人口30/40/30%，7人口16/30/54%。采用云顶人口机制的三档适配，参考表的4/5费权重合入本作最高3费；共享池耗尽时，实际概率在仍可抽的费用间重分配。

商店16名英雄均有画像，1/2/3费分别使用白/绿/蓝边框。三人存活时，落单者对阵另外一名存活棋手当前阵容的镜像；本体只结算自己的对局。第十回合不会强制结束；十一回合起基础伤害为6，每两回合再+1。

## 构建

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
pico-cli app install app/build/outputs/apk/debug/app-debug.apk --device PB331XPGL6040019G
pico-cli app launch com.pico.miniautochess --activity .platform.LaunchActivity --device PB331XPGL6040019G
```

上架构建使用 Android SDK 35、JDK 21 与公开 Spatial BOM 6.1.9，仅从公开 Maven 仓库解析依赖。安装命令不接受 `--format`。音效资源由 `python3 scripts/create_audio.py` 可重复生成，均为原创单声道 PCM。

## 实现与证据

- `app/src/main/java/com/pico/miniautochess/rules`：独立规则、英雄数据、战斗、AI；无 SDK 或 Android 依赖。
- `content/GameController.kt`：规则快照与UI；`ChessScene.kt`：棋盘与ECS；`CombatEffects.kt`：16种独立技能图案和池化命中特效；`ChessAudio.kt`：8声短音池、左右声道定位和可开关原创BGM。
- `PRODUCT.md`、`ART_DIRECTION.md`：规则与统一象牙/青玉美术规范。
- `docs/verification`：规则测试、100 局模拟、设备运行及源检查。
- `docs/models/STATUS.md`：5 个正式模型与后续模型的额度状态；商店另有16张画像。
- `PICO_AUTH_LOGIN_FINDING.md`：已给金燕提交的登录体验缺陷及证据边界。

V1.10连胜败与特效约定见 `docs/UX_V1_10.md`，本轮席位审计见 `docs/fairness-v1.10.0/report.md`；V1.9经营随机性约定仍保留。继承数值约定 `docs/UX_V1_8.md`、平衡证据 `docs/balance-v1.8.0/report.md` 与英雄数据 `docs/hero-data-v1.8.0.md`。交付说明为 `docs/verification/DELIVERY_V1_10.md`，安装包和源码位于 `dist/v1.10.0`。真机技能可见性、射线命中、阅读舒适性、听感及战斗90 FPS目标需要佩戴实测；规则模拟不能代替这项验证。

V1.6六类程序动作覆盖16名英雄，包含备战席/待机/行走/普攻/施法/庆祝；五个GLB没有骨骼，本轮为整体姿态动画，十一名程序造型可以摆动四肢。血条每100刻度、每500加粗，蓝条每5刻度，显示当前/上限；亭子补正面横梁、接实椽子与屋顶，庭院增加座椅和莲花水盆。右侧“音乐：开/关”控制低音量循环音乐。完整新模型与专业骨骼动画等待额度。

继承分区材质、程序动画、近战绕行和战斗特效；原十二张商店图片保留，新增四名英雄补齐独立画像。十一名程序英雄保留独立武器、头饰轮廓；五个正式GLB保留。灯笼柱顶补了承台。本轮没有新增收费3D任务。
