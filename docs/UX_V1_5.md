# V1.5 交互与规则增量

沿用8×8棋盘和底部TFT式经营区。只增加当前请求涉及的卡池、技能、羁绊和反馈。

- 点击概率栏，在同一面板查看人口概率表、刷新首格实际费用概率、各英雄余量；再次点击返回商店。V1.6.2已替换本版原有回合概率表，当前概率只随人口等级变化，详见 `UX_V1_6_2.md`。
- 棋盘与备战席共用选择状态，选中整体金色、边框金色；取消恢复材质。拖到已有棋子的位置原子互换，两个方向及满人口均允许。点选后点另一棋子同样交换。
- 升级新增人口、升星合成消耗上场副本时从备战席补位；六人口可放六人、七人口可放七人。没有备用英雄时不会凭空生成。
- 每个英雄有姓名条；旧程序造型补了不同日轮、羽饰、晶核、星珠、叶冠和宽刃。新增钟杖、荆冠、碑盾、大锤四名英雄，使羁绊高档可达。旧十二张画像保留，新增四张使用专属字符徽记。
- 棋盘与备战席常驻血条、空蓝槽；战斗蓝条按实际法力填充，100满蓝施法并清空。友方青玉、敌方陶红生命，蓝色法力、象牙护盾；死亡隐藏全部头部标记。
- 星标、姓名和状态条按英雄模板高度和星级缩放定位。填充置于深色底槽上方及前方，保留不被自身底槽遮住的间隙。
- 羁绊显示当前人数和全部档位，达到的门槛带方括号；阵营2/4，卫士法师1/3/5，射手1/2/3，辅助1/3。
- 三人时落单者随机打另两人之一的当前锁定阵容镜像。镜像满血、负UID，不扣本体血、不发本体金币、不占卡池。
- 终局四列等宽、姓名单行、生命与胜场明确行高，修截图里文字叠在一起的问题。
- 六盏庭院灯笼均增加柱顶承台，柱顶0.68m、承台0.68–0.73m、灯笼底0.73m，支撑连续。

佩戴验收重点：状态条是否清晰、姓名是否挡棋子、底部新增概率栏是否舒适、两种输入的双向交换、升至六人口后上满六人。代码和逻辑测试不能替代佩戴效果。
