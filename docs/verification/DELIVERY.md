## 修复说明

- 缓存 mesh/material 在一枚菜单棋子销毁时释放，导致准备阶段创建 AI 预览崩溃。将共享工厂资源设为 `toGlobal()`，先销毁场景实体，再配对关闭资源；十回合和重开均未再触发该异常。
- 单帧超过两秒不等于用户离开应用。改用 Stage 容器 ON_UNFOCUSED 事件暂停，ON_FOCUSED 后仍需手动继续；初次加载/返回的首帧丢弃历史 delta，前台对局继续按真实 delta 推进。转头离开视野不触发暂停。
- 未变更的菜单、准备和暂停场景不重复写实体属性。战斗插值仍在 ECS；没有用这项改动推断帧率。
- 音效使用原创单声道 PCM，通过公开 `ObjectAudioComponent`、`AudioResource` 和控制器播放。后台战斗不出声，切换观战和暂停会停止已有音效。

## 剩余范围

- 正式英雄模型 5/12，七名暂用不同造型的开发棋子。12 张生成参考图已经齐备。按当前方案七名预计 1260 点，最后核验余额 100，缺口约 1160；未充值或发布。详见 `../models/STATUS.md`。
- 苔木守卫出现在 99/100 局冠军阵容中，需要后续平衡验证；尚未宣称数值已平衡。
- 真机手柄命中精度、可读性、颈部/空间布局舒适度、声音方向感与 90 FPS 目标需要佩戴实测。播放 API 接受不等于听感验收。
- Stage 焦点监听按匹配版本公开示例实现；通过实际头显退出/返回触发 ON_UNFOCUSED 的完整冻结验证尚待佩戴检查。Android HOME/设置探测不等价。
- 五面板是当前可访问合同范围。动态 3D 棋格/棋子的完整屏幕阅读器合同未覆盖，不宣称全场景无障碍完成。
