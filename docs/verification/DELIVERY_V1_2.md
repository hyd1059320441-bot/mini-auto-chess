# 青玉棋会 V1.2

2026-11-07。本轮直接使用 B3110 真机 PB331XPGL6040019G，没有启动模拟器、提交收费模型任务或重新登录。

## 真机反馈对应修改

- 开战自动补位：手动准备和倒计时共用补位入口，只使用已有备战英雄。保留已经摆好的站位、装备、金币和英雄池；全在备战席时也可点击准备。
- 近战卡位：增加带连续碰撞检查的半格 A* 绕行、可达目标选择和射程边缘容差。攻击前检查近战线路，避免隔着队友攻击；没有随机瞬移或扩大基础射程。
- 底部布局：金币经验在左、五张英雄卡居中、操作在右，均属于同一条底部面板。选中英雄和装备详情在原位置切换。移除远处三个小字棋手面板，四席状态统一显示在近处。
- 实测适配：Spatial Attachment 真机内容宽度上限为 1280dp，因此最终 HUD 使用 1280×450dp；五张卡实测约 156–157dp 宽。英雄名与职业/价格分行显示，主要文字 28–36sp。
- 俯视与朝向：主棋盘中心降至 `(0, 0.48, -1.9)` 米，棋盘保持水平、模型保持直立，通过头部追踪自然俯视。己方准备、备战席和展示棋子默认朝敌方；战斗跟随目标转向。
- 材质：五个生成模型保留实际纹理，铜盾卫的无彩纹理改为铜色/冷钢且保留原明暗；七个程序模型加入布料纹理、皮肤、冷钢甲胄、阵营色与黄铜饰件。
- 特效：原生 ParticleComponent 点发射、加法混合贴图刀光、箭线、符文闪电、护盾罩、治疗上升光环、火焰横扫和范围冲击环。箭线平行棋盘，避免正面观察时变成侧面。最多24个特效实体、每发射器24粒子，只对当前观战播放；暂停、切换和终局清理暂态效果。

- 100局逻辑模拟：全部完成，金币、人口、位置、英雄池与配对守恒。中位546.5秒，最长641.2秒；1930场战斗，140场镜像，144场达到战斗时限。
- 原生样式检查与实验接口声明检查通过。Spatial 项目与真机交互审计均覆盖两块面板，0错误、0警告；原生按钮由实际真机查询与点击验证。
- 真机首次战斗：三次购买后不手动上场，点击准备，日志从0/3自动补齐到3/3。己方三名英雄分别攻击5、9、16次，并各自施放技能；两场全部12名英雄都有攻击记录，最大连续阻塞0.1秒。
- 当前观战第一轮播放102次特效，最高同时10个，丢弃0次；原生日志确认粒子组件实际添加与回收。
- 最终交付包再次真机运行：第一轮播放163次特效，最高同时11个，丢弃0次；原生粒子组件添加61次、回收61次，所有12名参战英雄均有攻击和技能记录，最大阻塞0秒。日志未发现致命异常、GPU_NO_RETIRE、初始化异常或内存错误。回合结算阶段的暂停/继续按钮及暂停状态也通过实际点击验证。

- 五个实际GLB均有1024×1024纹理，纹理包含色彩与明暗变化；运行日志记录五个原生纹理绑定及七个程序模型分区材质。天空球继续核验完整白色RGBA因子，避免变暗回归。
