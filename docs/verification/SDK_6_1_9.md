# Vibe Lab 构建：公开 Spatial SDK 6.1.9

本次按用户要求，将 V1.4 的上架构建从 Spatial BOM 6.2.8 改为公开版本 6.1.9。上架版本名为 `V1.4.0`，versionCode 为 6，包名仍为 `com.pico.miniautochess`。

## 公开依赖

`settings.gradle.kts` 的插件和依赖仓库均移除了内网 Maven。保留 Google、Maven Central、Gradle Plugin Portal，以及公开仓库：

`https://artifact.bytedance.com/repository/Volcengine`

该仓库的 BOM 元数据实际列出 6.1.9；同仓库的 6.2.8 POM 返回 HTTP 404。没有使用 Maven Local、项目外 AAR、私有凭据或内网仓库补齐依赖。

核验入口：

- [公开 BOM 元数据](https://artifact.bytedance.com/repository/Volcengine/com/pico/spatial/bom/maven-metadata.xml)
- [6.1.9 官方源码包](https://artifact.bytedance.com/repository/Volcengine/com/pico/spatial/core/core/6.1.9/core-6.1.9-sources.jar)

## 兼容性改动

- 材质采用 6.1.9 的公开 `getBaseColorTexture()` 和 `setBaseColorTexture()`。五个正式 GLB 的基础色纹理均使用默认 UV 通道，没有 `KHR_texture_transform`，无需新版纹理参数接口。
- 6.1.9 的粒子组件仅支持修改已加载的 Editor 粒子，不能公开新建。战斗火花改为复用网格：24 个效果槽，每槽最多 8 个火花，总上限 192。刀光、箭线、闪电、护盾、治疗和冲击波继续使用原来的纹理网格动画。视觉效果仍需实际观察，不能将此次兼容改动表述为与旧粒子逐像素相同。
- 移除 6.1.9 不存在的 `AccessibilityComponent` 和 `setAccessibilityActions` 调用；保留实际交互使用的 SpatialUI 按钮、手柄/眼手手势与拖拽逻辑。原 6.2.8 的无障碍合同及运行证据不适用于此构建。
- 应用图标改为青玉骑士棋子，并移除模板图标的 3D 图层元数据。发布 JPEG 从实际应用 PNG 等比例编码转换，未改变图案。
- 应用 Manifest 显式声明现有手柄、手势及眼动能力，与发布配置对齐。

没有改动自走棋规则、经济结算、人口扣血或英雄数值。没有新增收费模型任务，也没有使用模拟器。

用户戴头显协助操作，保持 SDK 6.1.9，没有调用自动相机移动或 Spatial Accessibility 操作。通过 `pico-cli capture record start/stop` 的同一录制会话，采集了实际招募、拖动布阵、自动战斗和回合推进过程。
