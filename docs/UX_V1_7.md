# V1.7：拖动、出售与继续决胜

公开Spatial SDK保持6.1.9，版本V1.7.0/code11。全场景沿相同的应用正前方-Z再移动10cm，累计z=-.30m。棋子模型保留85%尺寸，姓名、状态条与星标保持原尺寸。

缩小棋子后拖动困难来自英雄命中体同步缩小，以及备战席使用高.30m的碰撞体抢占脚部射线。英雄改用固定.21×.34×.21m命中盒，中心y=.15，底部覆盖到根节点下.02m；宽度小于.23m棋格间距。备战席改用.22×.05×.22m薄命中盒，棋盘/备战席全部40个槽位建立slot→entity映射，命中占用槽位同样发起对应己方棋子的原生拖动。权限仍由DragPlacement判断。

状态条原来只用模板高度和抬升，未计入倾斜、旋转、摆动四肢的边界。改为对visual body在pawn root坐标内读取recursive视觉包围盒；状态条、星标和姓名共享中心XZ，各自位于实际maxY之上，排除状态装饰与碰撞体。SDK同步缓存可能需要一帧，新克隆尚无边界时暂用模板高度。保留有限数字锚点日志；视觉居中和舒适性由佩戴验证。

按住棋子本体或脚下占用槽位后，商店保持展示卡牌；中央卡牌区域为出售区，左右操作栏与底部提示不属于出售区。Compose测量中央区域的实际布局边界，先转换为Attachment本地中心坐标，再通过SDK转换到arena坐标。拖动预览进入该区域后贴近倾斜面板、区域金色描边并显示“松手卖出×× · 返还×金币”。移出撤销出售提示；松手仅调用一次原规则sell。取消、暂停、托管、进入战斗、被卖或合并、权威槽位改变均不能误卖。

商店补齐晨钟先知、藤冠巫女、晶碑守望和赤锤破阵的独立画像，删除钟/藤/晶/锤文字替代。全部16名英雄采用图片；卡片按1/2/3费使用3dp白#F5F5F5、绿#55C76B、蓝#4B91FF边框，购买禁用时仍保留品质色。新增仅为2D画像，没有新增收费SGS模型任务。

取消第十回合强制终局和UI“/10”。三人存活时保留一场正常配对，落单者轮换并从另外两名存活棋手随机复制本轮锁定阵容；负UID镜像不占卡池、不改变本体的经济/生命/胜场。继续对战直到存活人数≤1。十一回合起基础伤害为6，每两回合+1，保持“基础伤害+对方存活人口”的规则。

战斗计时区分前台时间wallElapsed与战斗时间elapsed。前25秒按1倍固定.1秒战斗步；未结束的战斗随后每个前台步执行两个战斗步，移速、攻速、回蓝、回血、技能与动作/特效同步加速。UI显示“2倍加速”与最多15秒的加速剩余时间；已结束的另一场不会重新运行或结算。暂停冻结两种时间，观战只改变显示。40秒仍僵持才比较存活人数和剩余生命比例，以避免回血阵容无限拉长单场战斗。

验证覆盖拖动出售的各星级金额/份数、取消和权限变化、出售区边界、三人第10–12轮继续及轮换、两种时间、暂停/观战/镜像不重复付钱；100局模拟要求终局≤1存活者。B3110验证范围为安装、启动、版本、数字几何与崩溃记录，不要求截图，不将启动结果代替手柄验收。
