方法沿用V1.9：四席同为FLEX，真人托管，种子1001–1400。审计允许真人死亡后继续决出冠军，实际应用仍是真人死亡即终局；每步核验卡池、金币、人口与真实配对守恒。复现入口为[scripts/SeatFairnessAudit.java](../../scripts/SeatFairnessAudit.java)，编译与执行方法见[V1.9报告](../fairness-v1.9.0/report.md#复现修改后审计)。
