# V1.7.1：真人终局、文字行高与拖动选中

版本V1.7.1/code12，公开Spatial SDK 6.1.9。场景保留累计前移30cm和85%模型尺寸。

真人生命扣到0的同一个规则步立即进入FINISHED，不等待另一个AI对局。已完成对局的真实参战者只结算一次基础收入、利息和经验，包括刚淘汰的真人；中断对局不产生胜负与收入。镜像不影响被复制棋手。真人存活时，AI被淘汰仍按三人镜像继续决胜。终局计时归零，规则时间和战斗保持冻结。

进入终局关闭卡池/玩法详情和选中状态，展示真人名次、当轮扣血与收入、“再开一局”。尚存活AI显示“未完赛”，不宣称实时第一名已经夺冠。重新开始重置生命、经济、卡池、阵容、配对、战斗、结果及计时。

用户图片中的卡池长段落字号26sp，但继承的小行高导致多行相互挤压。卡池统一显式26sp/33sp，标题28sp/35sp；同样修正羁绊、玩法、卡牌、按钮和状态区的放大字体。保留滚动阅读和现有1280×600dp面板布局。

原生拖动期间以drag.uid作为选中来源，模型持续金色；脚下外框放大且柔和脉动，头顶姓名之上显示“拖动中”。材质与文本纹理复用，不逐帧创建资源。拖到商店出售预览继续显示售价；松手、取消、卖出、暂停、托管或阶段切换清除拖动标记并恢复原材质。

自动化验证侧重真人立即死亡、镜像死亡、另一场先结束、经济和卡池只结算一次、三人继续、重新开局以及100局终局冻结。布局与标记使用既有SDK公开API；6.1.9保留Compose语义，不引入不支持的AccessibilityComponent。佩戴视觉和拖动反馈由用户真机确认，不采集截图。
