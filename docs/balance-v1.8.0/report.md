# V1.8.0 平衡迭代与验收

16英雄/3费档/7人口；所有对打直接调用APK对应的生产Kotlin Battle，没有平行伤害模拟器。竞品机制与官方版本实例的出处见[V1.7.1审计](../balance-v1.7.1/report.md#参考游戏的设计依据)。本轮采用其星级预算、独立技能曲线和魔法反制思路，没有声称照抄竞品当前数值。

## 方法与门槛

七类预设阵容，在36/48/60金三个基础购买预算分别对打。合成花费按1/3/9份计算；各阵容允许±1金，固定星级分配，实际构成在armies.csv。训练种子1–4；最后验证站位种子201–224。左右有向配对均执行；含固定前排、分散、随机错列。固定布局重复不是独立玩家样本。

门槛：同英雄升星不出现倒挂；同职业同星级高费输出/前排总体占优，辅助同时看团队支援；七类阵容在所有预算合计的验证得分均25%–75%；验证超时判定不超过10%；低费三星与高费二星两条路线都有对局可赢。具体预算和配对允许强势期与克制，不要求逐配对50%。得分=胜1、平0.5、负0。

## 最终改动

- 生命/攻击保留1/1.8/3.24；五名法师采用独立技能曲线，晨钟1星360；范围技能副目标65%。
- 法师技能10/20/35%、初蓝20/30/40；基础魔抗20，卫士增加8/20/36，辅助全队增加10/25。
- 射手攻速10/25/40%；25秒后的治疗、回血与新增护盾50%，将僵持转为可结束的对局。
- 自动布阵使用实际生命、双防、DPS、技能目标数/施法周期、全队羁绊和前排覆盖；整组搜索保留手动锁定位置，费用不当战力。新增三种经营策略用于对照，游戏默认仍为灵活经营。
