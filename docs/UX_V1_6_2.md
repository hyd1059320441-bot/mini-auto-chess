# V1.6.2：场景、棋子尺寸与人口概率

沿用公开 Spatial SDK 6.1.9。按已确认范围直接修改现有应用，不生成新模型。

全场景沿应用正前方-Z再移动.10m，scenePlacement累计z=-.20m。placementOwner仍为局部identity，棋盘、备战席、商店、庭院与面板一起移动；HUD遮挡审计按观察者在owner坐标中的位置计算。

主棋盘、备战席、菜单展示与其他棋手预览的英雄模型统一缩小15%。星级仍每级增加7%，最终模型系数为`.85 × (1 + (star - 1) × .07)`；动作抬升乘.85。状态条、姓名和星标保持尺寸，高度随缩小后的造型与抬升更新。英雄碰撞体同步缩小并跟随星级，备战席落点保持原尺寸。

费用概率唯一来源为`Catalog.odds(level)`，函数和所有调用都移除round参数。免费换店、手动刷新和AI共用同一规则；升级后下一次抽卡使用新等级，现有商店不会因购买经验免费刷新。UI底栏显示当前人口概率，详情显示全人口表并高亮当前等级。

共享池规则保持：抽费用再按该费用剩余份数抽英雄；商店占用份数，刷新先归还自己的旧卡。某费用耗尽时，将该费用权重归零，其余有概率且有卡的费用重新归一；0%费用不会被解锁。详情“首格实际概率”按归还旧商店后的池计算，因此池耗尽时可能与基础表不同。

验证覆盖人口表合法性与趋势、相同等级/池/种子在1–10回合的连续商店一致、购买经验后立即使用新等级、每等级多种子10000抽分布、空池与份数守恒、既有规则回归及100局完整模拟。构建后安装B3110并核验版本、场景启动、位移、比例配置和安装包哈希；佩戴视觉与射线舒适性由用户确认。
