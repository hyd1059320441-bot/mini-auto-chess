# V1.10.0 连胜败经济与战斗表现

## 连胜与连败

四席共用GameEngine及Catalog规则；signed streak正数表示连续胜场、负数表示连续败场。反转胜负从1场重新计数，平局清零，重开四席清零。

| 连续胜/败场数 | 本轮额外收入 |
|---|---:|
| 0–1 | 0 金 |
| 2–3 | 1 金 |
| 4 | 2 金 |
| 5 及以上 | 3 金 |

真实交锋确认结果时更新计数；胜利仍立即发1金。随后在回合结算快照金币余额并计息，再一次性支付基础5金、利息与连胜败奖励。新增连胜败奖励不参与自身当轮计息。例：已有3连胜、18金，赢下第4场后先变19金，利息1，额外2，最终27金。

镜像只更新落单真实棋手的结果；被复制棋手只根据自己的真实对局更新一次连胜败。致死落败的真人仍支付已完成结果一次；其他未完成对局不虚构收入。HUD显示当前连胜败、奖励和预计利息；回合结果显示实际收入分项。

## 可读技能

| 技能类别 | 主图案/主要持续效果 |
|---|---:|
| 护盾 | 1.80 秒 |
| 治疗 | 1.60 秒 |
| 范围法术 | 1.50 秒 |
| 单体法术 | 1.30 秒 |
| 横扫 | 1.20 秒 |
| 强化箭 | 1.35 秒 |

前60%时长保持亮度，后40%淡出。环与图案展开，治疗向上升、护盾球旋转，火花跟随本效果生命周期；护盾和治疗主图案跟随对应英雄。16种图案与技能色保留。副目标使用较轻的0.6秒命中光，避免范围技能重复生成完整主图案。

所有时长按前台实际秒数播放。战斗2倍加速不再次压缩特效时长；表现不消耗规则随机数，不改伤害、治疗或回蓝数值。

## 普攻弹道

射手有箭头与箭杆，法师/辅助的远程普攻使用能量球；有方向明确的拖尾和到达位置反馈。箭矢轻微抛弧，能量球直线，依距离飞行0.30–0.55秒。近战继续使用挥砍。

CombatEvent捕获发动时的双方坐标与逻辑时间；飞行使用固定端点，英雄移动或死亡不丢失终点。弹道属于视觉表现，伤害仍在原固定战斗步结算；没有新增命中判定或延迟伤害，因此不改原英雄数值平衡。

## 生命周期和资源

- 特效40槽，每槽最多6个火花（240）；弹道独立32槽，普攻不占技能槽。
- 技能主图案优先，可替换较低优先级命中光；池满时丢弃低优先级反馈，实体数量不增长。
- 共享Plane/Sphere网格与纹理。材质预先创建并在离开场景时关闭，不引入实时灯。
- 暂停冻结当前效果；恢复后继续。切换观战跳过已发生事件，换回合、重开清理原特效；首个战斗帧的新事件允许播放。
- 不补播超过0.6秒的旧事件，避免前台卡顿后爆发历史攻击画面或声音。

## 验证

6项连胜败回归：四席账本及单次支付、对称档位、胜负切换/平局/重开、计息边界、致死结算、镜像不污染本体。3项表现回归：亮度与可读时长、五方向/零距离的弹道端点、生产事件坐标在死亡后仍不可变。全量121项通过，并重新运行100局默认AI、150局三策略及400局同策略席位审计。

SDK仍为公开6.1.9，两处既有Attachment的空间无障碍审计缺口保留。构建/规则测试与启动池日志不证明佩戴时的视觉可读性、真实交互或帧率；用户自行佩戴B3110观察技能、弹道、暂停恢复与满人口效果。
