# V1.9.0 战斗经营、终局与随机性

## 战斗与结算期间

- 买牌、刷新、买经验、卖出备战棋子均走原GameEngine经济接口；没有免费补款。
- 备战席棋子可点选移动、原生拖动、互换、拖到商店出售；上场棋子禁止移动或出售，自动布阵按钮禁用。合法落点只显示备战席。
- 合成只取备战席的同名同星副本，可连续合成至三星。上场副本保留原UID、星级、站位，当前Battle及Fighter不变。
- 若合成需要上场副本，下一轮beginPreparation先执行合成，再补齐空余人口，保留原手动站位。满备战席不能借用锁定棋盘副本腾位，拒绝购买时金币/商店/卡池保持原值。
- 战斗买经验即时提升等级并改变后续刷新概率，当前参战人数不增加。人口栏分别显示“本场”“下轮”。
- 暂停、淘汰、终局仍禁止经营；阶段切换、暂停、托管或权威位置变化取消拖动。

## 终局

只在Phase.FINISHED显示原生Spatial AlertDialog。真人最后存活且排名第一显示“胜利”；真人生命归零显示“失败”。正文显示名次、回合、胜场。按钮为“再来一局”和“退出”，退出调用LocalSpatialNavigator.closeStage()。

单回合胜负继续显示在上方状态区。真人淘汰即终局，已有真实参战结果只支付一次；其他存活AI标记未完赛。重开重置规则、画面选择、计时与卡池，并换新对局随机种子。

## 人机行动与重开

三个AI每局分别随机分配灵活经营、偏搜低费、偏升级。席位名字不绑定强势风格。首批购买等待2–4秒，其后升级和两批刷新各间隔0.8–2秒。按“准备完毕”会先完成所有待办经营，再生成锁定Army；花费规则一致。

首轮发牌起始席位随机，每轮轮换，避免固定一方一直先取共享池。基础种子加每局递增的固定混合步长产生新种子，同一基础种子的重开序列仍可复现。

四席仍共享一个有限池；每人的五格商店独立随机抽取并预留卡池份数。因此同人口使用相同基础概率，但共享池中剩余卡、既有商店预留和经营决策会造成每局结果不同。

## 验证范围

新增回归覆盖战斗经营账本、四席Battle/Fighter锁定、满席拒买、备战合成连锁、下轮延迟合成、拖动/交换/出售、暂停冻结、AI思考延迟、重开可复现及终局标题。

公平报告使用修改前/后各400局，四席相同灵活经营、种子1001–1400，并在测试入口允许真人淘汰后继续决出冠军。实际应用仍维持真人淘汰即结束。详见[fairness-v1.9.0/report.md](fairness-v1.9.0/report.md)。

V1.9没有改动V1.8英雄数值，历史平衡对打不能当作本轮重新执行的结果。SDK公开6.1.9未升级；两个既有Attachment的Spatial Accessibility声明仍受SDK能力限制。居中弹窗、原生射线拖动与阅读效果由用户佩戴头显确认。
